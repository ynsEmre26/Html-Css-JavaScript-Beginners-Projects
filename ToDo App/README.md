# ✅ Todo App — Task Manager

A simple, fully responsive **Todo App** built with **HTML, CSS, and Vanilla JavaScript**.  
This app allows users to **add, complete, and delete tasks**, with **local storage** to keep tasks persistent across sessions.

---

## ✨ Features

- 📝 **Task Management** — Add, delete, and mark tasks as completed
- 💾 **Local Storage** — Saves tasks so they persist across sessions
- ⌨️ **Enter Key Support** — Quickly add tasks by pressing Enter
- 📱 **Responsive Design** — Works on all screen sizes

---

## 🛠️ Tech Stack

| Technology     | Purpose                                    |
| -------------- | ------------------------------------------ |
| **HTML5**      | App structure and content                  |
| **CSS3**       | Styling, layout, and dark mode styling     |
| **JavaScript** | App logic, DOM manipulation, local storage |

---

## 🧠 How It Works

- Users type a task in the input field and press **Enter** or click **Add** to create a new task.
- Tasks appear in a list with **checkboxes** to mark them completed and a **delete button** to remove them.
- JavaScript manages the **task array** and updates **local storage** whenever tasks are added, deleted, or completed.
- Dark mode toggles the **body class** to switch themes instantly.
- Fully responsive layout ensures the app works well on desktop, tablet, and mobile devices.
